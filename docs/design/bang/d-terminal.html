! runs in a terminal

Start a message with ! and the box turns into a terminal line. The command runs in a real terminal next to the agent (same computer, same folder), shows live in the thread, takes your typing when it asks for something, and when it ends the output goes to the agent.

Not: a new character in the conversation, or a trip to another tab. The terminal is the thing; what runs it stays out of sight.
